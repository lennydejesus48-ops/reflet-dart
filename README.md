# Site de l'association Reflets d'Art

Site public : https://lennydejesus48-ops.github.io/reflet-dart/

- `index.html` : le site (HTML, CSS et JavaScript, sans framework).
- `images/` : les photos des œuvres et des portraits.
- `donnees-site.json` : les données de départ (artistes, actualités, équipe, textes), importées une fois dans Firestore.
- `firestore.rules` : les règles de sécurité de la base de données (à coller dans la console Firebase, onglet Règles).
- `artistes.html`, `sitemap.xml`, `robots.txt` : pour Google.

Données en ligne : Firebase (plan gratuit Spark), projet `reflet-dart`.
Administrateur : lennydejesus48@gmail.com.
